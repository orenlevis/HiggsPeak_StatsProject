# Raw Data Access

The full raw dataset (~10 GB) used in this project is hosted on Google Drive due to its size.

You can access the data here:

https://drive.google.com/drive/folders/1XXFkaOMLtb6zQpkaOcCHnT1BmveH0A99?usp=sharing

## Notes

- These are the original ROOT files from CERN Open Data (see README)
- Downloading all files may take significant time and storage
- Running the full data extraction notebook requires these files, yet the analysis notebook can be run without them.
